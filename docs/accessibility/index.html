Documentation / Get started

Make agent work usable.

Native controls, meaningful labels, and motion that respects user preferences.

Keyboard behavior

Buttons, links, checkboxes, radios, and disclosures use native HTML behavior. Use Tab to navigate. PromptComposer supports Command+Enter or Ctrl+Enter and avoids submitting during IME composition. Plain Enter creates a new line.

Status and feedback

Streaming state has a polite live region. Action failures use alerts. Context meters and progress elements carry accessible labels. Timeline status includes text so meaning does not depend on color alone.

Motion

Activity animations stop when the browser requests reduced motion. Loading text remains visible without animation.

Your app’s responsibilities

Use descriptive titles and action scopes. Keep focus stable as streamed content updates. Verify contrast after changing tokens, and test your complete workflow with a keyboard and screen reader. Components do not move focus when a server event arrives.

Verification limits

Native semantics are implemented in source. Browser, screen reader, and full WCAG conformance testing remain release acceptance work; this documentation does not certify conformance.
