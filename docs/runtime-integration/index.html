Documentation / Get started

Your runtime stays yours.

Connect typed props and callbacks to the state you already own.

Stream state into props

Adapt server events to the component’s public types in your application. AgentRun expects a run status and stable step IDs. ToolCall accepts structured input and output values. These components do not require a particular stream protocol.

Save a decision

Keep an approval pending until the server accepts a decision. Throw an error when the request fails so the component can display it.

"use client";
import { useState } from "react";
import { ApprovalRequest } from "@alvarovillalbaa/agentcn-ui";

export default function PublishApproval({ requestId }: { requestId: string }) {
  const [status, setStatus] = useState<"pending" | "approved" | "rejected">("pending");
  return <ApprovalRequest
    title="Publish this report?"
    description="This report will become visible to your team."
    scope={["Publish the reviewed report"]}
    status={status}
    onDecision={async decision => {
      const response = await fetch("/api/approvals/" + requestId, {
        method: "POST",
        headers: { "Content-Type": "application/json" },
        body: JSON.stringify({ decision })
      });
      if (!response.ok) throw new Error("The decision could not be saved.");
      setStatus(decision);
    }}
  />;
}

Server responsibilities

The example endpoint belongs to your application. It must authenticate the user, authorize the specific action, validate request state and scope, and enforce idempotency. A disabled button is a user experience behavior, not a server security boundary.

Cancellation and errors

Wire onStop or onCancel to your runtime’s cancellation mechanism. If a stream disconnects, preserve the last known state and show a recoverable error. Do not label an action completed until your runtime confirms it.

Generated content

ArtifactPanel and ToolCall render text and structured data. They do not evaluate code or render untrusted HTML. If you add a rich preview, give it an appropriate sandbox in your application.
