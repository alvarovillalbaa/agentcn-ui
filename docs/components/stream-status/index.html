Stream Status

Connection, generation, completion, and interruption states with token throughput.

Interactive demo
✳Generating response42 tok/s

Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add stream-status

Or import it from the package:

import { StreamStatus } from "@agentcn/react";

Import @agentcn/react/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
status"connecting" | "streaming" | "complete" | "error"Yes
labelstringNo
tokensPerSecondnumberNo
classNamestringNo

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Inspect the component
"use client";

import { cx } from "./_shared";
export interface StreamStatusProps {
  status: "connecting" | "streaming" | "complete" | "error";
  label?: string;
  tokensPerSecond?: number;
  className?: string;
}
export function StreamStatus({
  status,
  label,
  tokensPerSecond,
  className,
}: StreamStatusProps) {
  const labels = {
    connecting: "Connecting to model",
    streaming: "Generating response",
    complete: "Response complete",
    error: "Connection interrupted",
  };
  return (
    <div
      className={cx("ac-stream", className)}
      role="status"
      aria-live="polite"
      data-status={status}
    >
      <span className="ac-stream-indicator" aria-hidden="true">
        {status === "complete" ? "✓" : status === "error" ? "!" : "✳"}
      </span>
      <span>{label ?? labels[status]}</span>
      {tokensPerSecond !== undefined && status === "streaming" && (
        <span className="ac-muted ac-mono">
          {Math.max(0, tokensPerSecond)} tok/s
        </span>
      )}
    </div>
  );
}
