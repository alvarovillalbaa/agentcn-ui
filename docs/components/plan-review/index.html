Plan Review

Select execution steps and confirm a plan before your agent starts work.

Interactive demo
Execution plan

A plan before the first action

3 / 3 steps

Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add plan-review

Or import it from the package:

import { PlanReview } from "@agentcn/react";

Import @agentcn/react/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
titlestringYes
stepsPlanStep[]Yes
onStepChange(id: string, selected: boolean) => voidNo
onConfirm() => void | Promise<void>No
confirmedbooleanNo

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Keep the server authoritative.

Reviewing a decision in the interface does not authorize an operation. Validate the user, request, current state, and scope on your server before executing a callback’s action.

Inspect the component
"use client";

import { Surface, useAction } from "./_shared";
import type { SurfaceProps } from "./_shared";
export interface PlanStep {
  id: string;
  title: string;
  description?: string;
  selected: boolean;
  required?: boolean;
}
export interface PlanReviewProps extends SurfaceProps {
  title: string;
  steps: PlanStep[];
  onStepChange?: (id: string, selected: boolean) => void;
  onConfirm?: () => void | Promise<void>;
  confirmed?: boolean;
}
export function PlanReview({
  title,
  steps,
  onStepChange,
  onConfirm,
  confirmed = false,
  ...props
}: PlanReviewProps) {
  const action = useAction();
  return (
    <Surface
      {...props}
      title={title}
      eyebrow="Execution plan"
      actions={
        <span className="ac-tag">
          {steps.filter((s) => s.selected).length} / {steps.length} steps
        </span>
      }
    >
      <ol className="ac-list">
        {steps.map((s, i) => (
          <li key={s.id} className="ac-plan-step">
            <label>
              <input
                type="checkbox"
                checked={s.selected}
                disabled={
                  !onStepChange || s.required || confirmed || action.pending
                }
                onChange={(e) => onStepChange?.(s.id, e.target.checked)}
              />
              <span>
                <strong>
                  {i + 1}. {s.title}
                </strong>
                {s.description && (
                  <span className="ac-muted ac-block">{s.description}</span>
                )}
                {s.required && (
                  <span className="ac-muted ac-small">Required</span>
                )}
              </span>
            </label>
          </li>
        ))}
      </ol>
      {onConfirm && (
        <footer className="ac-footer">
          <button
            className="ac-button ac-primary"
            disabled={
              confirmed || action.pending || !steps.some((s) => s.selected)
            }
            onClick={() => void action.run(onConfirm)}
          >
            {confirmed
              ? "Plan confirmed"
              : action.pending
                ? "Confirming…"
                : "Confirm plan"}
          </button>
        </footer>
      )}
      {action.error && (
        <p className="ac-error" role="alert">
          {action.error}
        </p>
      )}
    </Surface>
  );
}
