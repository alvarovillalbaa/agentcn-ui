Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add approval-request

Or import it from the package:

import { ApprovalRequest } from "@alvarovillalbaa/agentcn-ui";

Import @alvarovillalbaa/agentcn-ui/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
titlestringYes
descriptionstringYes
scopestring[]Yes
inputunknownNo
risk"low" | "medium" | "high"No
status"pending" | "approved" | "rejected" | "expired"Yes
onDecision(decision: "approved" | "rejected") => void | Promise<void>Yes

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Keep the server authoritative.

Reviewing a decision in the interface does not authorize an operation. Validate the user, request, current state, and scope on your server before executing a callback’s action.

"use client";

import { Surface, JsonView, useAction } from "./_shared";
import type { SurfaceProps } from "./_shared";
export interface ApprovalRequestProps extends SurfaceProps {
  title: string;
  description: string;
  scope: string[];
  input?: unknown;
  risk?: "low" | "medium" | "high";
  status: "pending" | "approved" | "rejected" | "expired";
  onDecision: (decision: "approved" | "rejected") => void | Promise<void>;
}
/** A review surface. The application must authorize and execute decisions on its server. */
export function ApprovalRequest({
  title,
  description,
  scope,
  input,
  risk = "medium",
  status,
  onDecision,
  ...props
}: ApprovalRequestProps) {
  const { run, pending, error } = useAction();
  return (
    <Surface
      {...props}
      title={title}
      eyebrow="Human approval"
      actions={
        <span className="ac-risk" data-risk={risk}>
          {risk} risk
        </span>
      }
    >
      <p className="ac-body">{description}</p>
      <ul className="ac-scope">
        {scope.map((item, i) => (
          <li key={i}>
            <span aria-hidden="true">↗</span>
            {item}
          </li>
        ))}
      </ul>
      {input !== undefined && (
        <details className="ac-disclosure">
          <summary>Review exact payload</summary>
          <JsonView value={input} label="Approval payload" />
        </details>
      )}
      <footer className="ac-footer">
        {status === "pending" ? (
          <>
            <button
              className="ac-button ac-primary"
              disabled={pending}
              onClick={() => void run(() => onDecision("approved"))}
            >
              {pending ? "Saving decision…" : "Approve action"}
            </button>
            <button
              className="ac-button"
              disabled={pending}
              onClick={() => void run(() => onDecision("rejected"))}
            >
              Reject
            </button>
          </>
        ) : (
          <span role="status" className="ac-medium">
            Request {status}
          </span>
        )}
      </footer>
      {error && (
        <p className="ac-error" role="alert">
          {error}
        </p>
      )}
    </Surface>
  );
}
