Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add model-router

Or import it from the package:

import { ModelRouter } from "@alvarovillalbaa/agentcn-ui";

Import @alvarovillalbaa/agentcn-ui/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
modelsModelOption[]Yes
valuestringYes
onValueChange(id: string) => voidYes
disabledbooleanNo

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Inspect the component
"use client";

import { useId } from "react";
import { Surface } from "./_shared";
import type { SurfaceProps } from "./_shared";
export interface ModelOption {
  id: string;
  name: string;
  provider: string;
  description: string;
  badge?: string;
  disabled?: boolean;
}
export interface ModelRouterProps extends SurfaceProps {
  models: ModelOption[];
  value: string;
  onValueChange: (id: string) => void;
  disabled?: boolean;
}
export function ModelRouter({
  models,
  value,
  onValueChange,
  disabled,
  ...props
}: ModelRouterProps) {
  const id = useId();
  return (
    <Surface {...props} title="Model routing" eyebrow="Intelligence layer">
      <fieldset className="ac-fieldset" disabled={disabled}>
        <legend className="ac-sr-only">Choose a model</legend>
        {models.length === 0 && (
          <p className="ac-empty">No models available.</p>
        )}
        {models.map((m) => (
          <label className="ac-model" key={m.id} data-selected={m.id === value}>
            <input
              type="radio"
              name={id}
              value={m.id}
              checked={m.id === value}
              disabled={m.disabled}
              onChange={() => onValueChange(m.id)}
            />
            <div className="ac-grow">
              <div className="ac-row">
                <strong>{m.name}</strong>
                {m.badge && <span className="ac-tag">{m.badge}</span>}
              </div>
              <span className="ac-muted ac-small">
                {m.provider} · {m.description}
              </span>
            </div>
          </label>
        ))}
      </fieldset>
    </Surface>
  );
}
