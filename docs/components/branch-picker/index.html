Branch Picker

Explore alternative paths through a conversation without losing your place.

Interactive demo
Explore alternatives

Conversation branches

Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add branch-picker

Or import it from the package:

import { BranchPicker } from "@alvarovillalbaa/agentcn-ui";

Import @alvarovillalbaa/agentcn-ui/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
branchesConversationBranch[]Yes
valuestringYes
onValueChange(id: string) => voidYes

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Inspect the component
"use client";

import { Surface } from "./_shared";
import type { SurfaceProps } from "./_shared";
export interface ConversationBranch {
  id: string;
  title: string;
  preview: string;
  messages: number;
}
export interface BranchPickerProps extends SurfaceProps {
  branches: ConversationBranch[];
  value: string;
  onValueChange: (id: string) => void;
}
export function BranchPicker({
  branches,
  value,
  onValueChange,
  ...props
}: BranchPickerProps) {
  return (
    <Surface
      {...props}
      title="Conversation branches"
      eyebrow="Explore alternatives"
    >
      {branches.length === 0 ? (
        <p className="ac-empty">No conversation branches yet.</p>
      ) : (
        <ul className="ac-list">
          {branches.map((b) => (
            <li key={b.id}>
              <button
                className="ac-branch"
                aria-pressed={b.id === value}
                onClick={() => onValueChange(b.id)}
              >
                <span className="ac-row">
                  <strong>⑂ {b.title}</strong>
                  <span className="ac-muted ac-small">
                    {b.messages} messages
                  </span>
                </span>
                <span className="ac-muted ac-block">{b.preview}</span>
              </button>
            </li>
          ))}
        </ul>
      )}
    </Surface>
  );
}
