Installation

Copy this component into your configured source directory:

$ npx agentcn-ui@latest add source-stack

Or import it from the package:

import { SourceStack } from "@agentcn/react";

Import @agentcn/react/styles.css once in your root layout when using the package. For source installs, import the CSS path from your agentcn.json.

API reference

Props are generated from the component’s TypeScript interface. Surface components also accept native section attributes such as className, style, and aria-label.

PropTypeRequired
sourcesSource[]Yes
titlestringNo

Behavior & integration

Interactive values are controlled by your application. Update the relevant props after a callback succeeds. Async action callbacks disable their controls while pending and display a thrown error without reporting success.

Only absolute HTTP and HTTPS URLs become links. Invalid URLs and other protocols render as plain titles.

"use client";

import { Surface, safeHref } from "./_shared";
import type { SurfaceProps } from "./_shared";
export interface Source {
  id: string;
  title: string;
  href: string;
  excerpt?: string;
  relevance?: string;
}
export interface SourceStackProps extends SurfaceProps {
  sources: Source[];
  title?: string;
}
export function SourceStack({
  sources,
  title = "Sources & evidence",
  ...props
}: SourceStackProps) {
  return (
    <Surface
      {...props}
      title={title}
      eyebrow="Grounding"
      actions={
        <span className="ac-muted ac-mono">{sources.length} sources</span>
      }
    >
      {sources.length === 0 ? (
        <p className="ac-empty">No sources attached yet.</p>
      ) : (
        <ol className="ac-source-list">
          {sources.map((s, i) => (
            <li key={s.id}>
              <span className="ac-source-index">{i + 1}</span>
              <div>
                {safeHref(s.href) ? (
                  <a
                    className="ac-source-title"
                    href={safeHref(s.href)}
                    target="_blank"
                    rel="noreferrer noopener"
                  >
                    {s.title} <span aria-hidden="true">↗</span>
                  </a>
                ) : (
                  <strong>{s.title}</strong>
                )}
                {s.excerpt && <p className="ac-muted">{s.excerpt}</p>}
                {s.relevance && <span className="ac-tag">{s.relevance}</span>}
              </div>
            </li>
          ))}
        </ol>
      )}
    </Surface>
  );
}
