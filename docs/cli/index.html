The CLI reference.

Install only the source you need, with predictable local changes.

npx agentcn-ui@latest <command>
pnpm dlx agentcn-ui@latest <command>

init

Create an agentcn.json file and themed stylesheet in an existing app. Interactive terminals prompt for palette, radius, and density. Use --yes for defaults.

npx agentcn-ui@latest init --yes --palette forest --radius rounded --density comfortable

add

Copy one or more named components, shared helpers, and CSS. Unknown names fail before any files are written. Identical files remain untouched.

npx agentcn-ui@latest add agent-run approval-request
npx agentcn-ui@latest add --all --dry-run

create

Create a new Next.js app directory. Existing destinations are refused. Installs are left to you.

npx agentcn-ui@latest create my-agent --preset research --yes

Presets: copilot, research, operations. Generated apps include local component source, a root layout, a starter page, TypeScript configuration, and package scripts.

list

Print all components with categories and descriptions.

Options

FlagBehavior
--cwd <directory>Project root
--palette <name>forest, ink, indigo, ember
--radius <name>sharp, rounded, soft
--density <name>compact, comfortable
--components <path>Component source directory (init/create)
--css <path>Stylesheet path (init/create)
--preset <name>Starter preset (create)
--yesUse defaults without prompts
--dry-runShow the write plan without writing
--overwriteReplace differing files after review
--allInstall every component (add)
--helpPrint usage
--versionPrint version

Failures

Invalid configuration, unknown names, path traversal, symlink destinations, and conflicting files return a nonzero exit code. File writes are preflighted but are not a filesystem transaction; keep your project under version control.
