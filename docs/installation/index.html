Documentation / Get started

Start with one component.

Use npm imports, or install editable source with npx and pnpm dlx.

Requirements

React 18.2 or 19, TypeScript, and a modern browser. The CLI needs Node.js 22 or newer. The Next.js starter uses the App Router. Tailwind and an AI SDK are optional.

Option 1: npm package

$ npm install @alvarovillalbaa/agentcn-ui

Import the stylesheet in your root layout or application entry:

import "@alvarovillalbaa/agentcn-ui/styles.css";

Then render a component:

import { ContextWindow } from "@alvarovillalbaa/agentcn-ui";

export default function Usage() {
  return <ContextWindow capacity={128000} segments={[
    { id: "conversation", label: "Conversation", tokens: 12000 }
  ]} />;
}

Option 2: own the source

$ npx agentcn-ui@latest init

Choose your palette, radius, and density, then add components:

$ npx agentcn-ui@latest add agent-run approval-request

The CLI creates agentcn.json, a stylesheet, the selected components, and a shared helper. It does not execute dependency installs. Review every planned change with --dry-run.

// app/layout.tsx
import "../styles/agentcn.css";

// In a client component:
import { AgentRun } from "@/components/agentcn/agent-run";

The @/ alias in this example must be configured by your app. Relative imports work too.

Start a new Next.js app

$ npx agentcn-ui@latest create my-agent --preset copilot --palette forest --yes
cd my-agent
npm install
npm run dev

The starter is a local demonstration. Connect its callbacks to a real agent API. You can also use pnpm install and pnpm dev.

Configure visually

The kit builder previews every design choice and generates matching install commands.

Initial release

Registry publication is pending. Until npm packages are published, build the repository and run node packages/cli/bin/agentcn.mjs in place of npx agentcn-ui@latest. See the repository README for local setup.
