Documentation / Get started

Choose how you own it.

One component system, two distribution models.

Use the package

Package imports keep updates in your package manager. Named exports support tree shaking, and individual entry points let you import only what you need. Styles are explicit so your app controls where they load.

import { AgentRun } from "@alvarovillalbaa/agentcn-ui";
// Or use the individual entry point:
import { AgentRun } from "@alvarovillalbaa/agentcn-ui/agent-run";

Copy the source

The CLI copies editable TypeScript and CSS into your repository. There is no remote registry dependency at install time: the component source is bundled with the CLI version. You can remove a prop, change markup, or replace styles without waiting for a release.

Updates are a review decision

Source installs never silently replace changed files. Run add --dry-run against the new CLI, compare the proposal, and use --overwrite only after reviewing the affected files. Shared helpers and CSS can affect every installed component.

Presentation and execution

Components describe state and capture intent. They do not own model credentials, authorize operations, or persist data. That boundary keeps them useful with AI SDK, custom WebSocket streams, local models, and server actions.
