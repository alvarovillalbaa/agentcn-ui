Build the interface
around the intelligence.

agentcn/ui is an open-source React library for the parts of an AI app that deserve their own interface.

A capable agent does more than generate a message. It uses tools, holds context, remembers preferences, delegates work, asks permission, and produces artifacts. These components make that work understandable and controllable.

Two ways to make it yours

Import the package ↗

Use typed React exports and a shared stylesheet. Upgrade through your package manager.

Own the source ↗

Copy individual components into your project with the CLI. Adapt every line.

A small, focused contract

Each component receives data and emits callbacks. Your application owns the agent runtime, networking, authorization, persistence, and state transitions. The library makes no model calls and stores no user data.

Start with your first component

$ npx agentcn-ui@latest init

Then add an execution timeline:

$ npx agentcn-ui@latest add agent-run

Import the generated stylesheet in your root layout and connect the component to your run state. The installation guide walks through both approaches.

Release status

This repository is in initial development. npm publication and the hosted website must be verified before the @latest commands are available. To work locally, use the repository instructions.
