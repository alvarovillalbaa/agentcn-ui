Documentation / Get started

Fit your existing system.

Scoped class names, CSS variables, and no required Tailwind setup.

Design tokens

Load the stylesheet first, then override variables. Components use ac- class names to avoid collisions with your app.

:root {
  --ac-bg: #ffffff;
  --ac-subtle: #f7f8f9;
  --ac-fg: #1a1d21;
  --ac-muted: #636b76;
  --ac-border: #e5e7eb;
  --ac-accent: #28624e;
  --ac-accent-fg: #ffffff;
  --ac-danger: #bb302e;
  --ac-success: #24724f;
  --ac-radius: 12px;
  --ac-space: 20px;
  --ac-font: inherit;
}

Dark mode

Apply data-ac-theme="dark" or the dark class to a containing element. The package does not change your application theme or write to local storage.

<div data-ac-theme="dark">
  <ContextWindow capacity={128000} segments={segments} />
</div>

Density

Set data-ac-density="compact" on a container, or override --ac-space. You can scope a different design to a single workspace using the ac-theme class.

Using shadcn/ui

Both libraries can coexist. Map agentcn variables to your existing theme tokens if you want a shared visual language. Source components use native controls and bring no competing primitive framework.
