Documentation / Get started

A small configuration surface.

Keep your design choices alongside your source.

agentcn.json is read by the source installer. Commit it with the components so future additions use the same design.

{
  "version": 1,
  "components": "components/agentcn",
  "css": "styles/agentcn.css",
  "palette": "forest",
  "radius": "rounded",
  "density": "comfortable"
}
KeyValues / meaning
version1
componentsRelative project directory for component source
cssRelative path ending in .css
paletteforest, ink, indigo, ember
radiussharp (4px), rounded (12px), soft (20px)
densitycompact (14px), comfortable (20px)

Changing a design

Edit the config and run the add command again. A changed stylesheet requires explicit --overwrite. Inspect the dry run first. Alternatively, update CSS variables directly.

Path handling

Paths are relative to your project root. Absolute paths, parent traversal, symlink destinations, and writes into Git metadata or node_modules are rejected. The CLI checks all destinations before beginning the write plan.

Share your kit

The configurator can export the same configuration and copy a URL containing your selected components and design settings. No account is required.
